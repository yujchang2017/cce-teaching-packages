# 4.6-IV 應對氣候錯誤/虛假訊息｜教案（13-15 歲，4×45 分鐘）

## 學習目標（對應 UNESCO LO 全覆蓋）
- **LO1 認知 (1050)**：能透過範例區分錯誤訊息 / 惡意訊息 / 虛假訊息。
- **LO2 認知 (1051)**：能將批判性媒體素養技能應用於社群媒體上的氣候貼文。
- **LO3 社交情感 (1052)**：能培養面對複雜媒體環境的適應力與批判思考情緒韌性。
- **LO4 行為 (1053)**：能主動尋找可靠來源、核實主張並負責任分享。

## 資料引用（≥3 dp；map.csv ≥2；MOE ≥1）
- **dp1** 56% 網民靠社群媒體看時事 (UNESCO/IPSOS 2023)
- **dp2** 85% 擔憂線上不實資訊 (UNESCO/IPSOS 2023)
- **dp3** 2/3 內容創作者分享前未查證 (UNESCO 2024)
- **dp6** >97% 氣候科學共識 (IPCC AR6)
- map.csv id **338** Climate Change Education curriculum；id **742** 嚴肅遊戲碳足跡 (NTNU)
- **MOE** 108 課綱核心素養 **B2 科技資訊與媒體素養**（《CCE 溪遊記》教案引用）

## WSA 四面向整合
- **課程 Curriculum**：社會（公民責任）× 自然（氣候科學）× 資訊（演算法／AI）主題統整。
- **校園 Campus**：設立『事實查核角』走廊公告、每週輪值刊登一則校園氣候查核。
- **社區 Community**：邀請 TFC 查核員線上講座；與家長共讀查核文章。
- **文化 Culture**：班級訂定「停、查、問、分享」四步公約，融入日常言論。

## 第 1 節｜訊息風暴：三種假訊息的臉 (45 min)
| 時間 | 活動 | 重點 |
|---|---|---|
| 0-5 | Hook：北極熊瘦骨圖轉傳情境 | 連結 dp1 56% |
| 5-15 | 三卡分類：mis / dis / mal informational | 定義建構 |
| 15-30 | 小組解構 3 則校園 LINE 轉傳範例 | LO1 |
| 30-40 | 公布 dp2 85%，小組反思「為何會上當」 | 社交情感 |
| 40-45 | 出場票：用自己的話寫下三種差異 | **形成性評量 1** |

**評量**：①出場票（概念正確率）②討論表現觀察表。

## 第 2 節｜SIFT 查核術：批判媒體素養實作 (45 min)
| 時間 | 活動 | 重點 |
|---|---|---|
| 0-5 | 複習＋dp3 2/3 統計衝擊 | 價值觀點 |
| 5-20 | 教師示範 SIFT（Stop, Investigate source, Find better coverage, Trace claims）| LO2 |
| 20-35 | 雙人實戰：查一則氣候社媒貼文（任務單 A） | 工具操作 |
| 35-42 | 上台報 1 則：來源、作者、共識比對 | MOE B2 素養 |
| 42-45 | 迷思糾錯：97% 共識 vs 「還在爭論」 | dp6 |

**評量**：①SIFT 工作單評分量表 ②口頭報告（CER：Claim-Evidence-Reasoning）。

## 第 3 節｜AI 深偽與情緒韌性 (45 min)
| 時間 | 活動 | 重點 |
|---|---|---|
| 0-5 | 播放 30 秒「似真似假」氣候影片 | 動機 |
| 5-20 | 反向圖搜＋元資料 mini workshop | LO2 技能 |
| 20-35 | 情緒地圖：看到震撼氣候圖你的身體反應？| LO3 韌性 |
| 35-42 | 兩難：祖母轉傳你的錯圖，你怎麼回？| 倫理 |
| 42-45 | 冥想 1 分鐘 + 情緒字卡 | 社交情感 |

**評量**：①情緒地圖自評 ②兩難情境書面回應（倫理推理 rubric）。

## 第 4 節｜學生治理專題：校園查核隊 (45 min)
| 時間 | 活動 | 重點 |
|---|---|---|
| 0-10 | dp5 32 國政策啟發：我們能做什麼？| 治理視野 |
| 10-30 | 分組設計「校園事實查核角」企劃：受眾、流程、倫理守則、推廣管道 | WSA Campus |
| 30-40 | Gallery walk + 同儕回饋貼 | LO4 行為 |
| 40-45 | 簽署班級「停、查、問、分享」公約 | WSA Culture |

**評量**：①專題企劃書 rubric（創新、可行、倫理）②公約簽署反思 150 字。

## 教師備課要點
- 三類假訊息的例子建議選**本學年真實事件**（教師當週更新）。
- 兩難情境避免羞辱家人，引導「同理＋事實」並行。
- 專題成果可延伸至校刊或家長日展示，銜接 WSA Community。
