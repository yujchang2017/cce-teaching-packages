# 人類造成的生物多樣性喪失及其後果 教案（Level IV, 13-15 歲）

## 教學資訊
- **Key_id**：2.5-IV
- **Topic**：Human-induced biodiversity loss and its consequences（人類造成的生物多樣性喪失及其後果）
- **Key Idea**：全球化、氣候變遷與貿易加劇流行病傳播、改變生物多樣性並透過入侵物種破壞生態系，同時盜獵與工業化捕撈重創在地動物與海洋生命。
- **年段**：國中 7–9 年級（13–15 歲）
- **建議節數**：4 節 × 45 分鐘 = 180 分鐘
- **授課語言**：繁體中文（關鍵英文：IPBES / CITES / CBD / keystone species / bycatch / 30×30）

## 學習目標（對應 UNESCO 三領域，源自 2.5-IV.csv，全覆蓋）

### 認知層（Cognitive）
- **C1（row 447）**：解釋盜獵對瀕危物種造成的有害影響。
- **C2（row 448）**：探索基石物種消失的連鎖反應，理解物種間相互依存。
- **C3（row 449）**：描述密集與工業化捕撈對海洋生態系的不利影響。
- **C4（row 450）**：確定並倡導永續的捕魚實踐。
- **C5（row 451）**：展示入侵物種的全球傳播以及它們如何破壞生態系。

### 社會情緒層（Social and Emotional）
- **S1（row 452）**：對因盜獵而瀕危的動物展現更高的覺察與關懷。
- **S2（row 453）**：對反盜獵與反過漁行動感受到啟發與行動意願。
- **S3（row 454）**：傾聽原住民 / 耆老口述原生生態故事（納入排灣、阿美、噶瑪蘭等在地敘事）。

### 行為層（Behavioural）
- **B1（row 455）**：參與在地 / 國家 / 國際組織的反盜獵行動。
- **B2（row 456）**：倡導小規模捕漁。
- **B3（row 457）**：選擇來自永續漁業的水產消費。
- **B4（row 458）**：參與在地入侵種移除行動。
- **B5（row 459）**：實踐以氣候調適方式保護在地生態系。

### 第 4 節（45 min）— 從我做起：WSA 整合與學生治理（行動競能）

#### Whole School Approach 四面向（國中強化學生治理）

- **治理 Governance**：成立『校園生態守護委員會』（學生代表 + 生物教師 + 家長會 + 在地保育團體代表）；提案由班聯會送校務會議，且每學期須向學生大會報告成效（治理深化）。
- **課程 Curriculum**：跨科整合——自然科（食物網、生態系）、社會科（CITES、全球貿易）、綜合活動（社區服務）、英語（IUCN 網站閱讀）、藝術與人文（保育海報 / 短片）。
- **校園營運 Operations**：校園入侵種定期清除（小花蔓澤蘭 / 銀合歡）；營養午餐選擇 MSC 認證或在地沿近海水產；禁售象牙 / 珊瑚飾品；設置『原生植物角』。
- **社群 Community**：與在地林業署、NGO（如 WildOne、臺灣動物社會研究會、荒野保護協會）合作；聽取原住民耆老分享口述原生物種（S3）。
